## Javascript Loops

Things I learnt:

- Loop basically means repeat this code
- let i = 0 → starting point
- i < 5 → condition
- i++ → increase by 1
- i += 2 → increase by 2
- i-- → decrease by 1
- array[i] → access the current array item
- array.length → determine how many items to loop through
- A variable like total can accumulate values during a loop.
