# JavaScript Arrays

Things I learnt:

- An array is used to store multiple values in one variable.
- Array indexes start from 0.
- I can access an item using its index, like `fruits[0]`.
- I can change an item by assigning a new value to its index.
- `.length` tells me how many items are in an array.
- `.push()` adds an item to the end.
- `.pop()` removes the last item.
- `.shift()` removes the first item.
- `.unshift()` adds an item to the beginning.
